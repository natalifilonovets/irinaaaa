# Практика англійської лексики

Інтерактивна вправа: 13 ситуацій із вибором слова або вислову, пояснення українською, результати та повторення помилок.

Відкрийте `index.html` у браузері. Встановлення та збирання не потрібні.

Клавіші `1` і `2` обирають відповідь. Інтерфейс адаптовано для телефона та комп’ютера.
